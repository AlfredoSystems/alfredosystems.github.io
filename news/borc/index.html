Introducing the MiniFRC Event Index: The Blue Alliance for MiniFRC

Written by Jacob Williams

Update, 22 Oct 2026: The event index has moved from borc.io to alfredosys.com/past-events. The borc.io domain is no longer owned by Alfredo Systems.

MiniFRC results have always lived in whatever spreadsheet, stream description, or Discord thread they were posted in, and they get harder to find every season. The MiniFRC Event Index is my fix for that: a single index of MiniFRC events, in the spirit of The Blue Alliance.

Every event gets its own page with four tabs. Rankings lists each team with their record and ranked points. Match Results has the full qual and playoff schedule with alliances, scores, winners, and links to the match on the event stream when a stream exists. Robots shows a photo of each robot that competed. Awards covers who took home what.

Eleven events are archived so far, going all the way back to MiniFRC 1 and running through MiniFRC 12: Rebuilt. Newer events also have a media gallery of event photos and videos.

The index is static and open source as part of this website's repository, AlfredoSystems/alfredosystems.github.io, with each event stored as JSON. If you have a photo of a robot that is missing from an event, please reach out or open a pull request!


Go check it out at alfredosys.com/past-events.
